# 비레스 5083 이야기 서고 시각 디자인 보강안

- 작성일: 2026-08-01
- 상태: 사용자 정정 지시에 따라 자체 확정
- 대상: `비레스 5083 이야기 서고` 공개 리더
- 선행 정본: `2026-08-01-default-start-reading-flow-design.md`

## 1. 목표

이 보강안은 명칭과 데이터만 바꾸는 기능 패치가 아니다. 비레스의 실제 세계 장면과 렌·듀란의 승인 원본을 첫 화면에서 보여 주어 서브컬처 작품의 입구라는 신호를 강화하면서, 사용자가 곧바로 시작 장면을 고르고 문서를 읽는 현재 기능을 유지한다.

다음 원칙을 함께 만족한다.

1. 첫 화면에서 `VIRETH 5083`, 세계 장면, 렌·듀란과 시작 선택 일부가 동시에 보인다.
2. 거대한 장식용 hero나 별도 마케팅 랜딩을 만들지 않는다.
3. 시작 선택 8개는 각각 다른 실제 장면 이미지를 사용한다.
4. 인물과 장면 위의 글자는 국소 어두운 오버레이로만 대비를 확보한다.
5. 본문과 참고 설명은 밝은 독립 배경과 진한 글자를 사용한다.
6. 렌·듀란은 서고의 시각적 길잡이이며 기록의 저자, 화자, 사건 당사자로 표현하지 않는다.

## 2. 조사에서 채택한 원칙

기존 비레스 홍보 HTML의 시작 카드에서 검증된 다음 방식을 유지한다.

- 실제 가로 장면을 카드 전체에 보인다.
- 왼쪽 텍스트 뒤에만 강한 어두운 오버레이를 두고 오른쪽 장면은 보존한다.
- 각 카드가 서로 다른 장소와 시간대를 보여 준다.
- 페이지 바깥 테마와 무관하게 각 구역이 자체 배경색과 글자색을 가진다.

공식 서브컬처 게임 사이트에서 확인한 시각 문법은 다음처럼 제한적으로 가져온다.

- [Granblue Fantasy: Relink 캐릭터 페이지](https://relink.granbluefantasy.jp/en/characters/): 큰 인물 원화를 세로 패널로 보여 주면서 같은 화면에 다음 선택지를 남긴다.
- [Blue Archive 캐릭터 페이지](https://bluearchive.jp/character): 세계 배경과 캐릭터를 첫 화면의 강한 신호로 사용하고, 선택 조작을 이미지와 함께 둔다.

비레스 서고에는 게임식 장식과 수치 패널을 복제하지 않는다. 인물 컷인, 실제 장면, 명확한 선택 상태만 가져온다.

## 3. 비교한 접근법

### A. 작은 세계 무대와 이미지형 시작 탭

가로형 도시 장면 위 왼쪽에 확정 H1과 보조문을 놓고, 오른쪽에 렌·듀란의 세로 인물 컷인을 배치한다. 바로 아래에는 8개 시작 장면을 가로 스크롤 가능한 이미지 탭으로 보여 준다.

장점은 첫 화면의 작품 신호와 선택 기능을 동시에 보존한다는 점이다. 데스크톱에서는 활성 상황 본문 일부까지, 모바일에서는 시작 탭과 활성 장면의 시작 부분까지 보이게 할 수 있다.

**선택한다.**

### B. 전체 화면 비주얼노벨형 hero

세계 장면과 인물을 가장 크게 보여 줄 수 있지만 시작 선택과 독서 기능을 접힘 아래로 밀어낸다. 서고의 목적보다 홍보 화면이 앞서므로 제외한다.

### C. 이미지가 들어간 자료실 대시보드

기존 좌측 레일에 작은 썸네일만 추가하면 가장 안전하지만 렌·듀란과 세계의 첫 인상이 약하고 현재 화면의 관리 도구 느낌을 충분히 바꾸지 못한다. 제외한다.

## 4. 화면 구조

### 4.1 고정 헤더

- 브랜드 키커: `VIRETH 5083`
- 헤더 이름: `이야기 서고`
- 세계 링크: 딱딱한 `세계 안내` 대신 `비레스를 둘러보기`
- 읽음 상태: 현재 브라우저 저장임을 짧게 표시
- 세계 링크에는 Lucide `Map` 아이콘을 사용한다.

### 4.2 작은 세계 무대

- 최대 높이는 데스크톱 260px, 모바일 330px로 제한한다.
- 왼쪽에는 다음 확정 문구를 둔다.
  - H1: `내 시작상황과 이어지는 이야기를 읽어보세요.`
  - 보조문: `편지, 장부, 공문과 사건 기록 속에서 비레스의 이름과 생활 방식을 알아갈 수 있습니다.`
- 배경은 기존 비레스 도시 원본을 비파괴 파생한 가로 장면으로 사용한다.
- 오른쪽에는 렌과 듀란의 승인 개별 원본을 세로 패널처럼 배치한다.
- 인물 아래에는 이름만 `REN`, `DURAN`으로 표시한다. 본문 화자나 저자라는 표현을 쓰지 않는다.
- 접근성 설명에는 두 인물이 `비레스의 여행자이며 기록 속 화자와 별개의 시각 안내`임을 명시한다.

### 4.3 시작 선택

- 구역 제목은 관리 용어인 `시작상황` 대신 `내 이야기는 어디서 시작할까?`로 쓴다.
- 8개 선택은 `button` 기반의 이미지형 탭으로 렌더링한다.
- 각 탭은 고유 장면 이미지, 순서, 짧은 제목, 읽음 상태를 포함한다.
- 왼쪽 국소 오버레이는 텍스트 영역까지만 강하고 오른쪽으로 빠르게 투명해진다.
- 활성 탭은 테두리, 밝기, `aria-selected`로 구분한다.
- 키보드의 좌우 방향키, `Home`, `End`, `Enter`, `Space`를 지원한다.
- 탭 접근성은 [WAI-ARIA Tabs Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)을 따른다.

### 4.4 활성 장면과 추천 이야기

- 큰 활성 장면은 기존 가로 이미지와 장면 설명을 유지한다.
- `이 상황과 맞닿은 기록`은 `이 장면과 함께 읽을 이야기`로 바꾼다.
- 문서 여는 조작은 Lucide `BookOpen`과 `펼쳐 읽기`를 함께 사용한다.
- 진행 상태에는 Lucide `CircleCheck`, 전체 진행에는 `Compass`를 사용한다.
- 아이콘만 쓰는 이전·다음 조작에는 `title`, `aria-label`과 명확한 포커스 표시를 제공한다.

### 4.5 본문과 참고 설명

- 기존 14편의 HTML, 문단 순서와 삽화 30개는 그대로 유지한다.
- 본문 종이는 현재보다 밝은 중립색으로 두고 본문 글자는 최소 `#111713`, 굵기 700 이상을 유지한다.
- `읽고 나서 참고`는 종이 프레임 밖의 별도 `aside`로 둔다.
- 실제 heading과 `ul > li > dfn + p` 구조를 사용한다.
- 참고 설명 뒤에만 읽음 완료 조작을 둔다.

파생은 배경 제거, 리사이즈와 무손상 원본 보존만 수행한다. 인물의 복장, 얼굴과 색은 편집하지 않는다. 상단에서는 투명 인물을 텍스트와 분리된 전용 영역에 배치하고, 모바일에서는 해당 영역을 문서 흐름 안에 두어 텍스트를 침범하지 않게 한다.

## 6. 색과 형태

- 고정 헤더: 짙은 청록
- 주요 본문: 밝은 회백색과 백색
- 강조: 녹청, 적색 망토 계열, 황금색을 분리해 사용
- 카드 반경: 최대 6px
- 프레임은 상황 탭, 문서 행, 리더와 참고 설명처럼 실제 조작 또는 문서 단위에만 사용
- 페이지 구역 전체를 떠 있는 카드처럼 만들지 않는다.
- 화이트모드에서도 모든 구역은 자체 배경과 글자색을 가진다.

## 7. 검증

기능 정본의 기존 검증에 다음을 추가한다.

1. 데스크톱 1440x1000 첫 화면에서 세계 장면, 렌·듀란, 시작 선택 일부가 함께 보인다.
2. 모바일 390x844 첫 화면에서 H1이 잘리지 않고 시작 선택 일부가 보인다.
3. 렌·듀란의 보이는 라벨과 대체 설명이 저자나 사건 당사자로 오해시키지 않는다.
4. 8개 탭의 이미지가 모두 로드되고 서로 다른 파일을 사용한다.
5. 이미지 탭의 배경이 밝은 막에 묻히지 않고 텍스트 대비가 유지된다.
6. 아이콘 조작마다 텍스트 라벨 또는 접근 가능한 이름이 있다.
7. 문서 본문, 모든 삽화, 참고 설명, 읽음 조작 순서에 겹침과 잘림이 없다.
8. 공개 UI, 이미지 대체문과 생성 데이터에 폐기 명칭이 없다.
9. 배경과 인물 자산에 말풍선, 설명 상자, 읽을 수 있는 글자가 없다.
